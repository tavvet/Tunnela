# Tunnela

[English](README.md) · **Русский**

Приложение для Windows, которое подключается к вашему серверу [TrustTunnel](https://github.com/TrustTunnel/TrustTunnel).

Tunnela дополняет официальный TrustTunnel CLI компактным интерфейсом, меню в трее и службой Windows. Импортируйте конфигурацию, выберите правила маршрутизации и подключитесь. VPN-сервер и данные для подключения нужно предоставить самостоятельно.

**Статус:** ранняя предварительная версия. Установщик пока не подписан. Проверенные сценарии и оставшиеся ограничения описаны в [статусе проверок](docs/BUILD-STATUS.md).

## Возможности

- **Профили серверов:** создание и редактирование подключений, импорт поддерживаемых конфигураций TOML и статических ссылок `tt://`.
- **Раздельная маршрутизация:** весь трафик через VPN, кроме выбранных адресов, или только выбранные адреса через VPN. Правила поддерживают домены, IP-адреса, подсети CIDR и предусмотренные форматом выражения с портами.
- **Параметры подключения:** HTTP/2 или HTTP/3, DNS-серверы, поддержка IPv6 и сертификаты сервера.
- **Фоновое подключение:** отдельная служба Windows управляет туннелем; меню трея позволяет управлять подключением и выходом из приложения.
- **Понятный статус:** доступность службы, запущенный процесс клиента и подтверждённое VPN-подключение отображаются отдельно.
- **Локальные профили:** сохранённые учётные данные и настройки зашифрованы средствами Windows DPAPI для вашей учётной записи Windows.
- **Английский и русский языки:** по умолчанию выбран английский. Для перехода на русский откройте **Settings → Interface language → Русский**. Затем язык можно менять в **Настройки → Язык интерфейса**; выбор применяется сразу и сохраняется автоматически.
- **Диагностика:** просмотр событий службы и экспорт отчёта без конфигураций профилей и учётных данных.

## Начало работы

Нужны Windows 10 или новее на x64, права администратора для установки службы и рабочая конфигурация сервера TrustTunnel. Приложение включает среду выполнения .NET и VPN-движок; отдельно устанавливать .NET не требуется.

Готовые сборки ищите в разделе [Releases](https://github.com/tavvet/Tunnela/releases). Если установщика ещё нет, воспользуйтесь [инструкцией по сборке](#сборка-из-исходников) ниже.

1. При обновлении Tunnela отключите VPN в приложении и закройте его через меню трея перед запуском установщика.
2. Запустите EXE-установщик. При первой установке подтвердите учётную запись Windows, которая будет управлять VPN. Обновления сохраняют эту учётную запись и ваши профили.
3. Откройте **Tunnela** из меню «Пуск» под своей обычной учётной записью Windows.
4. В разделе **Серверы** выберите **Импорт TOML**, **Вставить конфигурацию** или **Добавить**. Проверьте параметры и нажмите **Сохранить**.
5. При необходимости измените правила выбранного профиля в разделе **Маршрутизация**.
6. Перед подключением вручную отключите любой другой VPN и дождитесь завершения его туннеля. Откройте **Подключение**, выберите сервер и нажмите **Подключиться**.

Служба запускается вместе с Windows, но ждёт ручной команды подключения. При закрытии окна в трей туннель продолжает работать. Команда **Отключиться и выйти** отключает VPN и завершает приложение; **Закрыть интерфейс…** закрывает только GUI.

Установка, обновление и удаление описаны в [INSTALL.md](docs/INSTALL.md). Удаление Tunnela сохраняет профили. Существующая установка TrustTunnel и её данные автоматически не переносятся и не удаляются.

## Текущие ограничения

- Маршрутизация по приложениям не поддерживается выбранной интеграцией с CLI.
- Ссылки подписки, автоматические обновления и автоматическое подключение VPN при запуске не реализованы.
- Kill switch движка CLI не гарантирует сохранение блокировки после аварии клиента или остановки службы. Аварийные сценарии требуют дальнейших проверок.
- Правила маршрутизации принадлежат отдельным профилям серверов. Общих наборов правил пока нет.

Tunnela управляет одним туннелем для всего устройства. Одновременные подключения нескольких VPN не входят в поддерживаемый план проверки. Подробности — в [плане ручных проверок](docs/TESTING.md).

## Сборка из исходников

Разработка и сборка выполняются на Windows. Используются C# / .NET 10, WPF и отдельная служба Windows. Скрипты используют локальный SDK внутри проекта; Visual Studio и инструменты C++ не требуются.

В PowerShell клонируйте репозиторий и соберите установщик:

```powershell
git clone https://github.com/tavvet/Tunnela.git
cd Tunnela
.\scripts\bootstrap-sdk.ps1
.\scripts\build-installer.ps1
```

Сборка установщика запускает изолированные тесты, подготавливает закреплённые версии TrustTunnel CLI **1.1.7** и Wintun **0.14.1** и использует локальный компилятор NSIS **3.13**. Версия SDK закреплена в [global.json](global.json). Первая сборка требует доступа в интернет для загрузки зависимостей; установка из готового EXE работает без интернета.

При сборке этой версии создаётся файл:

```text
.artifacts\installer\Tunnela-0.1.0-preview.3-Setup-x64.exe
```

Чтобы отдельно собрать, проверить и опубликовать GUI и службу:

```powershell
.\scripts\build.ps1 -Publish
```

Результаты помещаются в `.artifacts\publish\tunnela\desktop` и `.artifacts\publish\tunnela\service`. Эти команды не устанавливают приложение, не запускают службу и не подключают VPN. Инструменты сборки, зависимости и результаты остаются в каталогах проекта, исключённых из Git.

## Исходные проекты

Tunnela — независимая оболочка. TrustTunnel остаётся VPN-движком, а Wintun предоставляет драйвер туннеля для Windows. Лицензии сторонних компонентов включены в установщик.

- [TrustTunnel](https://github.com/TrustTunnel/TrustTunnel)
- [TrustTunnel Client](https://github.com/TrustTunnel/TrustTunnelClient)
- [Wintun](https://www.wintun.net/)
